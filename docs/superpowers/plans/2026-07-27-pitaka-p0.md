# Pitaka P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working React Native e-wallet app running in Expo Go — login, home with a config-driven service grid, send money, and transactions — backed by an append-only centavo ledger and local fixtures, with every unit under test.

**Architecture:** One repo (`pitaka-app`). No Firebase, no WebView, no `prebuild`, no native modules, no server. The Remote Config payload is read from a local fixture through the exact same zod-validated parser the real thing will use later, and the wallet is an in-memory append-only ledger. Every seam that P1 will later replace with a real implementation (config source, wallet API) sits behind a module boundary that already has tests, so swapping it is a change of one file, not a rewrite.

**Tech Stack:** Expo SDK 57 (Expo Go), React 19.2.3, React Native 0.86, TypeScript (strict), expo-router, zod, Jest via `jest-expo`, `@testing-library/react-native`.

## Global Constraints

- **Money is always integer centavos.** No `float` or decimal ever represents money. Formatting to `1,234.56` happens only at the display edge. No test may assert on a floating-point money value.
- **Balance is derived, never stored.** A balance is `SUM(amount_centavos)` over ledger entries for an account. There is no mutable balance column anywhere.
- **Every money movement is zero-sum.** Entries written by one operation must sum to exactly `0` across accounts.
- **Config is parsed with zod `safeParse`, never bare `JSON.parse`.** Any parse failure falls back to bundled defaults and logs; it must never throw into a render path.
- **TypeScript `strict: true`.** No `any` in committed code.
- **TDD.** Every task writes a failing test first, watches it fail, then implements the minimum to pass.
- **Node 24.14.1, pnpm 10.33.0.** Package manager is pnpm; never npm or yarn.
- **Author writes feature code.** Tasks marked *(rails)* may be agent-generated; tasks marked *(author)* are hand-written by Troy — the agent supplies the failing test and the interface only.

> **Four things the scaffold actually required that this plan originally guessed
> wrong** — recorded because they cost real time and will bite again on the H5 repos:
> 1. SDK 57's default template puts routes in **`src/app/`**, not `app/`. All route
>    paths below are corrected; relative imports from a route are `../features/...`.
> 2. `@testing-library/react-native` v14 **registers its matchers automatically**.
>    The old `setupFilesAfterEnv: ['@testing-library/react-native/extend-expect']`
>    now fails with "module not found".
> 3. pnpm stores real packages under `node_modules/.pnpm/<name>@<ver>/node_modules/`,
>    which the conventional `transformIgnorePatterns` regex does not match — so React
>    Native's own ESM setup files were left untransformed and every test died with
>    "Cannot use import statement outside a module". Fixed by setting
>    `transformIgnorePatterns: []`.
> 4. SDK 57 ships no `babel.config.js`; Jest needs one declaring `babel-preset-expo`.
>    Also set `compilerOptions.types: ['jest']` — the Expo base config does not
>    pick up `@types/jest` on its own.
> 5. **`render` is async in RTL Native v14.** It returns a Promise, so every
>    component test must be `async` and `await render(...)`. Skipping the await
>    fails with the thoroughly misleading "`render` function has not been called",
>    and destructuring gives "getByText is not a function". Every component test
>    in Tasks 8–14 below is written `async`; keep it that way.
> 6. **`fireEvent` is async too, and this one fails silently.** `fireEvent.press`
>    and `fireEvent.changeText` also return Promises under React 19's concurrent
>    renderer. Without the `await`, the state update has not landed by the time the
>    next line asserts — so the test fails claiming the element or text is missing,
>    pointing at the assertion rather than the un-awaited event. There is no error
>    message hinting at the real cause. Every `fireEvent` in this plan is awaited,
>    and any helper that fires events is `async` and awaited at its call site.
> 7. **Query MPIN by regex, not exact text.** `MpinInput`'s accessibility label is
>    `MPIN, 2 of 6 digits entered`, so `getByLabelText('MPIN')` finds nothing.
>    Use `getByLabelText(/MPIN/)`.

```ts
/** An integer number of centavos. Never a float. */
export type Centavos = number

export function formatCentavos(amount: Centavos): string {
  const negative = amount < 0
  const abs = Math.abs(amount)
  const pesos = Math.trunc(abs / 100)
  const cents = abs % 100
  const grouped = pesos.toString().replace(/\B(?=(\d{3})+(?!\d))/g, ',')
  const body = `${grouped}.${cents.toString().padStart(2, '0')}`
  return negative ? `-${body}` : body
}

const AMOUNT_PATTERN = /^\d+(\.\d{1,2})?$/

export function parseAmountToCentavos(input: string): Centavos | null {
  const cleaned = input.replace(/,/g, '').trim()
  if (!AMOUNT_PATTERN.test(cleaned)) return null
  const [whole, fraction = ''] = cleaned.split('.')
  const cents = fraction.padEnd(2, '0')
  return Number(whole) * 100 + Number(cents)
}
```

```ts
import type { Centavos } from './money'

export type AccountId = string

export type LedgerEntry = {
  id: string
  accountId: AccountId
  txId: string
  amountCentavos: Centavos
  createdAt: string
}

export function balanceOf(entries: LedgerEntry[], accountId: AccountId): Centavos {
  return entries
    .filter((e) => e.accountId === accountId)
    .reduce((sum, e) => sum + e.amountCentavos, 0)
}

export function isZeroSum(entries: LedgerEntry[]): boolean {
  return entries.reduce((sum, e) => sum + e.amountCentavos, 0) === 0
}

export function entriesForTx(entries: LedgerEntry[], txId: string): LedgerEntry[] {
  return entries.filter((e) => e.txId === txId)
}
```

```ts
import type { Centavos } from './money'
import { balanceOf, entriesForTx, type AccountId, type LedgerEntry } from './ledger'

export type TransferRequest = {
  from: AccountId
  to: AccountId
  amountCentavos: Centavos
  idempotencyKey: string
}

export type TransferResult =
  | { ok: true; txId: string; entries: LedgerEntry[] }
  | { ok: false; code: 'INSUFFICIENT_FUNDS' | 'INVALID_AMOUNT' | 'IDEMPOTENCY_KEY_REUSED' }

const txIdFor = (idempotencyKey: string): string => `tx:${idempotencyKey}`

export function applyTransfer(
  entries: LedgerEntry[],
  req: TransferRequest,
  now: string,
): TransferResult {
  const txId = txIdFor(req.idempotencyKey)
  const existing = entriesForTx(entries, txId)

  if (existing.length > 0) {
    const debit = existing.find((e) => e.accountId === req.from)
    const sameOperation = debit?.amountCentavos === -req.amountCentavos
    return sameOperation
      ? { ok: true, txId, entries: [] }
      : { ok: false, code: 'IDEMPOTENCY_KEY_REUSED' }
  }

  if (!Number.isInteger(req.amountCentavos) || req.amountCentavos <= 0) {
    return { ok: false, code: 'INVALID_AMOUNT' }
  }

  if (balanceOf(entries, req.from) < req.amountCentavos) {
    return { ok: false, code: 'INSUFFICIENT_FUNDS' }
  }

  return {
    ok: true,
    txId,
    entries: [
      { id: `${txId}:debit`, accountId: req.from, txId, amountCentavos: -req.amountCentavos, createdAt: now },
      { id: `${txId}:credit`, accountId: req.to, txId, amountCentavos: req.amountCentavos, createdAt: now },
    ],
  }
}
```

```ts
import { servicesGridSchema, type ServicesGrid } from './schema'
import { DEFAULT_GRID } from './defaults'

export { DEFAULT_GRID }
export type { ServicesGrid }

/**
 * Never throws. A malformed or unknown-shaped payload degrades to the bundled
 * default rather than taking a render path down with it.
 */
export function parseServicesGrid(raw: string | undefined): {
  grid: ServicesGrid
  usedFallback: boolean
} {
  if (raw === undefined) return { grid: DEFAULT_GRID, usedFallback: true }

  let json: unknown
  try {
    json = JSON.parse(raw)
  } catch {
    return { grid: DEFAULT_GRID, usedFallback: true }
  }

  const parsed = servicesGridSchema.safeParse(json)
  return parsed.success
    ? { grid: parsed.data, usedFallback: false }
    : { grid: DEFAULT_GRID, usedFallback: true }
}
```

```ts
import { z } from 'zod'
import type { Tile } from './schema'

export type NavIntent = { kind: 'native'; route: string } | { kind: 'h5'; url: string }
export type Flags = Record<string, string>

const greylistSchema = z.object({ enabled: z.boolean() })

/** Fail closed: an unreadable flag hides the tile rather than exposing it. */
function greylistAllows(flags: Flags, tileKey: string): boolean {
  const raw = flags[`greylisting_${tileKey}`]
  if (raw === undefined) return true

  let json: unknown
  try {
    json = JSON.parse(raw)
  } catch {
    return false
  }

  const parsed = greylistSchema.safeParse(json)
  return parsed.success ? parsed.data.enabled : false
}

export function resolveTile(tile: Tile, flags: Flags, h5BaseUrl: string): NavIntent | null {
  if (!tile.enabled) return null
  if (!greylistAllows(flags, tile.key)) return null

  if (tile.type === 'native') return { kind: 'native', route: tile.target }

  const base = h5BaseUrl.replace(/\/+$/, '')
  return { kind: 'h5', url: `${base}/h5/${tile.target}/` }
}
```

```ts
import { balanceOf, type AccountId, type LedgerEntry } from '../domain/ledger'
import { applyTransfer, type TransferResult } from '../domain/transfer'
import { ACCOUNTS, seedEntries } from './seed'

export type StoreTransferRequest = {
  to: AccountId
  amountCentavos: number
  idempotencyKey: string
}

export type WalletStore = {
  getEntries: () => LedgerEntry[]
  getBalance: (accountId: AccountId) => number
  transfer: (req: StoreTransferRequest) => TransferResult
  subscribe: (listener: () => void) => () => void
}

export function createWalletStore(initial: LedgerEntry[] = seedEntries()): WalletStore {
  let entries = [...initial]
  const listeners = new Set<() => void>()

  const notify = () => listeners.forEach((l) => l())

  return {
    getEntries: () => entries,
    getBalance: (accountId) => balanceOf(entries, accountId),

    transfer: (req) => {
      const result = applyTransfer(
        entries,
        { from: ACCOUNTS.user, to: req.to, amountCentavos: req.amountCentavos, idempotencyKey: req.idempotencyKey },
        new Date().toISOString(),
      )
      if (result.ok && result.entries.length > 0) {
        entries = [...entries, ...result.entries]
        notify()
      }
      return result
    },

    subscribe: (listener) => {
      listeners.add(listener)
      return () => listeners.delete(listener)
    },
  }
}
```

```tsx
              borderWidth: 1,

          />
```

```tsx
import React from 'react'
import { View, Text, TextInput } from 'react-native'
import { tokens } from './tokens'

type Props = {
  value: string
  onChangeText: (value: string) => void
  error?: string
}

const NATIONAL_LENGTH = 10

export function MobileInput({ value, onChangeText, error }: Props) {
  const handleChange = (next: string) => {
    // Filipino users habitually type the local 09XX form against a fixed +63,
    // which would otherwise produce +6309XX. Strip leading zeros.
    const digits = next.replace(/\D/g, '').replace(/^0+/, '')
    onChangeText(digits.slice(0, NATIONAL_LENGTH))
  }

  return (
    <View>
      <View
        style={{
          flexDirection: 'row',
          alignItems: 'center',
          borderWidth: 1,
          borderColor: error ? tokens.color.danger : tokens.color.border,
          borderRadius: tokens.radius.md,
          paddingHorizontal: tokens.space.md,
        }}
      >
        <Text style={{ color: tokens.color.textMuted, fontSize: tokens.font.md }}>+63</Text>
        <View style={{ width: 1, height: 24, backgroundColor: tokens.color.border, marginHorizontal: tokens.space.sm }} />
        <TextInput
          accessibilityLabel="Mobile number"
          value={value}
          onChangeText={handleChange}
          keyboardType="phone-pad"
          placeholder="917 123 4567"
          style={{ flex: 1, paddingVertical: tokens.space.md, fontSize: tokens.font.md, color: tokens.color.text }}
        />
      </View>

      {/* Reserved row: layout must not shift when an error appears. */}
      <Text style={{ minHeight: 18, marginTop: tokens.space.xs, color: tokens.color.danger, fontSize: tokens.font.sm }}>
        {error ?? ''}
      </Text>
    </View>
  )
}
```

```tsx
import React, { useRef, useState } from 'react'
import { View, Text, TextInput, Pressable } from 'react-native'
import { MobileInput } from '../../ui/MobileInput'
import { tokens } from '../../ui/tokens'
import { parseAmountToCentavos } from '../../domain/money'
import { ACCOUNTS } from '../../data/seed'
import type { WalletStore } from '../../data/walletStore'

type Props = { store: WalletStore; onDone: () => void }

export function SendMoneyForm({ store, onDone }: Props) {
  const [mobile, setMobile] = useState('')
  const [amount, setAmount] = useState('')
  const [error, setError] = useState<string | undefined>()

  // Generated once per form instance, so a double press replays the same
  // operation instead of creating a second one.
  const idempotencyKey = useRef(`send-${Date.now()}-${Math.round(Math.random() * 1e9)}`)

  const complete = mobile.length > 0 && amount.length > 0

  const submit = () => {
    const centavos = parseAmountToCentavos(amount)
    if (centavos === null) {
      setError('Enter a valid amount')
      return
    }

    const result = store.transfer({
      to: ACCOUNTS.peer,
      amountCentavos: centavos,
      idempotencyKey: idempotencyKey.current,
    })

    if (!result.ok) {
      setError(result.code === 'INSUFFICIENT_FUNDS' ? 'Not enough balance' : 'Could not send')
      return
    }

    setError(undefined)
    onDone()
  }

  return (
    <View style={{ padding: tokens.space.lg, gap: tokens.space.lg }}>
      <Text style={{ fontSize: tokens.font.lg, fontWeight: '700', color: tokens.color.text }}>
        Send Money
      </Text>

      <MobileInput value={mobile} onChangeText={(v) => { setMobile(v); setError(undefined) }} />

      <View>
        <TextInput
          accessibilityLabel="Amount"
          value={amount}
          onChangeText={(v) => { setAmount(v); setError(undefined) }}
          keyboardType="decimal-pad"
```

```tsx
import React from 'react'
import { View, Text, FlatList } from 'react-native'
import { AmountText } from '../../ui/AmountText'
import { tokens } from '../../ui/tokens'
import type { LedgerEntry } from '../../domain/ledger'

type Props = { entries: LedgerEntry[]; accountId: string }

export function TransactionsView({ entries, accountId }: Props) {
  const mine = entries
    .filter((e) => e.accountId === accountId)
    .slice()
    .sort((a, b) => b.createdAt.localeCompare(a.createdAt))

  if (mine.length === 0) {
    return (
      <View style={{ padding: tokens.space.lg }}>
        <Text style={{ color: tokens.color.textMuted }}>No transactions yet</Text>
      </View>
    )
  }

  return (
    <FlatList
      data={mine}
      keyExtractor={(item) => item.id}
      contentContainerStyle={{ padding: tokens.space.lg }}
      renderItem={({ item }) => (
        <View
          style={{
            flexDirection: 'row',
            justifyContent: 'space-between',
            alignItems: 'center',
            paddingVertical: tokens.space.md,
            borderBottomWidth: 1,
            borderBottomColor: tokens.color.border,
          }}
        >
          <View>
            <Text style={{ color: tokens.color.text, fontSize: tokens.font.md }}>
              {item.amountCentavos < 0 ? 'Sent' : 'Received'}
            </Text>
            <Text style={{ color: tokens.color.textMuted, fontSize: tokens.font.sm }}>
              {item.createdAt.slice(0, 10)}
            </Text>
          </View>
          <AmountText centavos={item.amountCentavos} />
        </View>
      )}
    />
  )
}
```
